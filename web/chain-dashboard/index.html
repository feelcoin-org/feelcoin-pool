Build Feelcoin Miner from source 
sudo apt update
sudo apt install -y git build-essential cmake libuv1-dev libssl-dev libhwloc-dev

git clone https://github.com/feelcoin-org/feelcoin-miner.git
cd feelcoin-miner
git checkout v0.1.0

mkdir -p build
cd build

cmake .. -DWITH_OPENCL=OFF -DWITH_CUDA=OFF
make -j$(nproc)

./feelcoin-miner --version

Frequently Asked Questions

Feelcoin mining basics.

How do I mine Feelcoin?

Use a RandomX-compatible miner such as XMRig. Connect to pool.feelcoin.org:4242 and use your Feelcoin wallet address as the username.

What password should I use?

Use x. The password field is required by the Stratum protocol but is not used for authentication.

What is the pool fee?

The Feelcoin pool fee is currently 0.5%.

What payout method is used?

The pool uses PPLNS reward accounting.

What is the minimum payout?

The configured minimum payout is 0.33 FEEL . Automatic payouts are currently disabled during the network testing phase.

How is mining difficulty handled?

Workers begin at difficulty 100 and the pool automatically retargets approximately every 30 seconds according to miner performance.

Does the pool support TLS?

Yes. Secure mining is available at pool.feelcoin.org:4244 using TLS 1.2 or TLS 1.3. For XMRig, enable TLS with --tls. The standard pool.feelcoin.org:4242 endpoint remains available for miners that do not use TLS.

What does an accepted share mean?

An accepted share means that your miner submitted valid work to the Feelcoin pool. Shares are used to determine each miner's contribution to pool rewards.
